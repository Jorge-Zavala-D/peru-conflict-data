# Manual adjudication

For AI_PI_RECONSTRUCTION_V1, follow docs/ai_pi_reference_evaluation_protocol.md. A source-first PI packet contains source/codebook but no candidate answers; retain the initial judgment before reveal. An assisted packet contains candidates and is labeled assisted. Agents may prepare packets, never invent a PI decision. Record actual author, time, rationale, evidence, reviewed fields/units, inventory-review scope, unresolved issues and supersession. Retain originals and append decisions/derived versions without replacing initial candidates. A second external reviewer is not a successor-route prerequisite; specialist consultation is optional when PI chooses it. Explicit legacy review workflows keep their original critical identity/casualty/benchmark-total second-review rule. Never edit canonical Parquet/DuckDB directly or relabel a synthetic decision real.
