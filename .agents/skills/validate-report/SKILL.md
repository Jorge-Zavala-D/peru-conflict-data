# Validate one report

Read docs/ai_pi_reference_evaluation_protocol.md for the active AI/PI route. Recompute arithmetic, source-based object counts, schema/provenance coverage, links, duplicates and parent-child constraints from independently read assigned evidence. Inspect apparent-negative/unprocessed units as well as generated rows. Classify `PARSER_ERROR`, `SOURCE_INCONSISTENCY`, `SOURCE_AMBIGUITY`, and missing evidence separately. Preserve initial predictions; report denominators, unsupported metrics and exact field versus inventory review. Mechanical quote/span checks and agreement are not scientific accuracy or PI approval. Create discrepancy/review candidates; never alter source values, references or canonical tables to make checks pass. Keep targeted queues distinct from probability audits and protected evaluation separate from development.
