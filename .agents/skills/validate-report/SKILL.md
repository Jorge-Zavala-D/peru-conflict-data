# Validate one report

Recompute arithmetic, object counts, schema/provenance coverage, and source-page links from independently read evidence. Classify `PARSER_ERROR`, `SOURCE_INCONSISTENCY`, `SOURCE_AMBIGUITY`, and missing evidence separately. Create discrepancy/review candidates; never alter source values, gold data, or canonical tables to make checks pass.
