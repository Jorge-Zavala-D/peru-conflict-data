# Release dataset

Confirm explicit release authorization and redistribution rights. Require immutable data files, dictionary, schemas, code commit, source coverage/hashes, benchmark and QA report, known issues, adjudication summary, taxonomy version, changelog, checksums, citation, and licensing statement. MIT covers software, not automatically source documents or derived-data rights. Never overwrite a release.
