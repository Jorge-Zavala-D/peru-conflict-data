# Source discrepancy

Record both values, report hashes, pages/sections/spans, verification method, and classification. Distinguish parser error, source inconsistency, ambiguity, missing evidence, cross-source conflict, and potential editorial error. A preferred analytical derivative, if needed, is a separate versioned record with rationale; never overwrite the source-oriented value.
