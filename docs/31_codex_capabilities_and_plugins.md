# Codex capability and minimal-tool policy

Required surfaces are local shell/Git/Python, authenticated GitHub and Dropbox access or equivalent read-only local evidence, browser/web retrieval, and official OpenAI documentation. Strong supporting capabilities include Context7, Playwright, planning, CI diagnosis, skill creation/installation, and subagents, but configured or cached does not mean active/authenticated. Prefer existing global/workspace capabilities over repository duplication. Generic filesystem/Git MCPs, opaque PDF AI services, and server databases are unnecessary while local filesystem/Git and DuckDB suffice. The verified environment, actual callable tools, configured-only services, authentication limits, and missing binaries are in `docs/codex_capability_inventory.md`.
