# Risk register

Major risks are incomplete archive coverage; revised PDFs; stale or misleading PDF metadata; template drift; scans; table row shifts; source contradictions; name/genealogy drift; boundary changes; missing-to-zero bias; model hallucination/cost; repeated OCR/model cost; direct canonical edits; large Git files; hard-coded local paths; excessive connector/plugin surface; dependency or system-binary failures; credential leakage; premature full-corpus runs; and over-harmonization. Controls include manifests/gap registry, content hashes and version preservation, empirical parser regimes, native-first extraction, page-level OCR, reconciliation/discrepancy records, explicit genealogy, time-aware geography, null semantics, source-span model protocol, caching, adjudication, external data root, minimal tools, lockfile/CI, benchmark gates, and original plus normalized fields.
