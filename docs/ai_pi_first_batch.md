## One thin extraction path

with page identities and coordinates. The visual PDF remains authoritative. Use
existing typed scientific v0.3.1 models and benchmark/metric v0.1.1 semantics,
including original Spanish values, literal dates, explicit missingness states and

source packets before seeing that candidate. Preserve both initial outputs before
comparison. The same model in two contexts is not statistical independence.

disagreement queue. Candidate agreement and schema success never create PI approval.

## Required outputs and stopping conditions

Write into an owner-approved external development directory, never raw storage or
canonical Parquet/DuckDB. Keep the initial reader outputs and raw responses separate
from PI decisions and corrected derivatives. The executing task must return:

- Typed relational machine candidates, complete provenance and source-unit coverage,
  including unsupported, failed, unprocessed and machine-empty states.
- Deterministic validation results, object omissions/duplicates, field and relationship
  disagreements, classified source inconsistencies and unresolved mapping issues.
- A source-first PI packet without candidate answers; a separate assisted packet with
  complete source units, candidate differences and exact anchors; a simple versioned
  CSV/JSON decision template, with PDF/HTML summaries and folder-opening fallbacks.
- Initial-versus-corrected identities; scoped technical/field/discovery metrics with
  actual denominators and review coverage; elapsed time, observable usage/cost and
  correction/review burden. No recall claim without a source-based denominator.

Stop on an inaccessible or mismatched source, accidental reserved-material exposure,
false provenance, systematic missing section, inability to preserve initial outputs,
budget exhaustion, unmanageable PI queue, or an unresolved required semantic choice.
Do not run a second revision or fresh evaluation automatically. Existing numerical
qualification targets remain inherited goals; any successor tolerance, confidence
interpretation or Object Threshold Policy A choice must be decided before final
evaluation and cannot be selected after viewing final test results.
