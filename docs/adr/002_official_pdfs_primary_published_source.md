# ADR 002: Official PDFs are the primary published source

Status: accepted, 2026-08-27.

## Context

The supplied 2015-2026 workbook overlaps only part of the monitoring system and may differ from published totals or concepts.

## Decision

Canonical source-preserving reconstruction begins from official report bytes and page evidence. The workbook is complementary administrative evidence for cross-source validation and normalization.

## Consequences

Workbook-only fields never define the published universe. Cross-source differences are discrepancies, not automatic corrections.
