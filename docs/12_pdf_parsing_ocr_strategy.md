# PDF parsing, tables, and OCR

Use native text first. Benchmark engines and coordinate strategies by document structure. Tables may later justify custom coordinate logic, pdfplumber, Camelot, or Tabula by table class. OCR only pages with unusable text layers, store it separately, record engine/language/version, and compare it to native evidence. Historical age alone does not imply OCR. M0 found native text on every page of reports 260-269; this is inventory evidence, not parser validation.
