# Project charter

Create research-grade public data infrastructure reconstructing social conflict as monitored and published by Peru's Defensoría del Pueblo, not all real conflict. The active [AI_PI_RECONSTRUCTION_V1](ai_pi_strategy.md) route uses progressive source-derived machine construction, substantive source-first PI audits and assisted adjudication, scoped PI-reviewed references, protected evaluation and explicit expansion/release decisions. Exhaustive double-external-human gold is not a prerequisite.

Success still requires official-source identity and coverage with acquisition gaps explicit, immutable hashed bytes/alternatives, empirically qualified format regimes, auditable linkage, field-level provenance, original Spanish values, unknown states, contradictions, append-only decisions, reproducible materialization and honest public limitations. Prepared materials and software passes are not scientific validation. Causal policy effectiveness or intergenerational transmission is not identified by reconstruction alone; a separate research agenda must distinguish measures from identification and unperformed analyses.
