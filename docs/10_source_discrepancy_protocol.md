# Source discrepancy protocol

Allowed classes are `PARSER_ERROR`, `SOURCE_INCONSISTENCY`, `SOURCE_AMBIGUITY`, `MISSING_SOURCE_EVIDENCE`, `CROSS_SOURCE_CONFLICT`, and `POTENTIAL_EDITORIAL_ERROR`. Preserve each value and its provenance, verify independently, classify with rationale, and route unresolved scientific consequences to review. If analysis needs a preferred derivative, create it separately with version and rationale. Arithmetic QA raises evidence packages and never fixes a source value automatically.
