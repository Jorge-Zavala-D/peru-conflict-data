# QA and validation

Where source concepts permit, independently test published arithmetic such as registered versus active/latent, type totals, phases, transitions, protests, casualties, and dialogue. Add strict schema/provenance checks, longitudinal continuity/anomaly checks, and complementary workbook comparisons. Failures create discrepancies; they never rewrite source evidence. Public release requires source hashes, documented schema/benchmark coverage, provenance, and no unaudited manual edits.
