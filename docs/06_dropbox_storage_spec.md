# External storage specification

`00_external` contains externally supplied immutable files; `01_raw` the immutable source corpus and the operational acquisition ledger under `01_raw/manifests/`; `02_extracted` mechanical text/layout/table/render/OCR evidence; `03_parsed` source-oriented objects; `04_linked` cross-report linkage/geography; `05_database` canonical Parquet/DuckDB; `06_validation` discrepancies, benchmarks, logs, and review; `07_releases` immutable releases; `99_archive` retained initialization or superseded working artifacts. The raw manifest ledger records discovery results, HTTP/retrieval receipts, retries, local paths, acquisition status, collision evidence, and alternate byte versions. Git stores its schemas, code, official-domain configuration, tests, and methodology, not a mutable duplicate ledger. A canonical normalized report manifest will later be materialized in Parquet/DuckDB, and release-specific inventories/checksums belong under `07_releases`. Code resolves this hierarchy through `CONFLICT_DATA_ROOT`, never a user-specific absolute path. Routine writes are allowed only in `02_extracted` through `07_releases`; M1-03 is a separately approved exception for raw acquisition.
