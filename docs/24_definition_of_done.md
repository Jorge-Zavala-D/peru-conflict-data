# Definition of done

M0 requires a reviewed foundation branch; live paths and permissions verified; existing MIT license preserved; safe data-root configuration; minimal tested dependencies and real lockfile; CI and pre-commit gates; strict versioned models/schemas; run metadata and structured logging; capability/live/bootstrap inventories; ADRs and execution plan; and evidence that no raw source changed. M0.1 additionally requires retaining `schemas/v0.1.0/`, synchronizing source-evidenced `v0.2.0`, a field-level dictionary, an explicit operational-manifest boundary, an identity-evidence guard, full local gates, and independent pull-request CI. M1 requires complete expected-report/month manifest statuses with explicit gaps, hashes, and revisions. M2 requires independently checked gold data and measured metrics. M3 proceeds only after benchmark acceptance or an explicitly approved revision. Every milestone requires a clean reproducible run, provenance, documented failures, and updated decisions.
