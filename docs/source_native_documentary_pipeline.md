# Source-native documentary pipeline V001

`SOURCE_NATIVE_DOCUMENTARY_PIPELINE_V001` ports the developmental native-word
algorithms into `peru_conflicts.execution.native_documentary`. It produces
documentary observations and published aggregate measurements, not conflict-case
identities, scientific reference judgments, canonical records or release data.
Scientific schema 0.3.1 and normative metric contract 0.1.1 are unchanged.

## Three separate operations

`pipeline.admit_native(contract, output)` validates a supplied complete native
JSON page, runs the unchanged `NATIVE_GEOMETRIC_REGION_RULES_V001` once, and seals
the candidate, word evidence, exclusive accounting partition and ambiguities.
Admission uses only geometry: line bands, horizontal runs, persistent gutters,
column occupancy, whitespace, overlaps and competing boundary hypotheses.
No heading vocabulary, ordinals, table identities or prior answers select regions.
The historical numerical rules are retained, including provisional spatial
splits at a gap greater than 1.25 times the local height scale. A spatial split
does not establish that a documentary table ended.

`receiver.receiving_only(contract, output)` reads a hash-bound frozen candidate
and coverage sidecar. It calls the same receiver used by composition, with
fail-on-call probes on both adapter entry points, their underlying generators,
composition and the unchanged engine. Eligible decisions are `would_dispatch`,
never executed extraction. This is a process-local safeguard, not an OS sandbox.

`pipeline.run_pipeline(contract, output)` seals admission and receiving decisions,
then conditionally invokes only explicitly permitted adapters. If eligible
regions exceed the actual run's adapter-call ceiling, all decisions are retained
and downstream generation stops; no preferred region is selected. Qualified
derivatives undergo direct word-transfer checks before profile compilation and
one permitted invocation of `SOURCE_ADDRESSED_TABLE_ENGINE_V001`. Failures are
preserved without a generator retry; attempted generator calls remain counted.

The thin CLI is:

```text
python scripts/process_native_documentary.py --operation admit|receive|compose|pipeline --manifest <private-run.json> --output <new-output>
```

Use the installed project environment and verify imports resolve to the intended
checkout. This command neither installs dependencies nor acquires/renders sources.
Invented tests run without private data or private code imports.

## Inputs and run scope

The JSON manifest declares the public version, `mode` (`invented` or `actual`),
`coordinate_representation`, `source` (report identity and PDF hash), and `input`
(native path, byte size/hash, physical page, dimensions and reference identity).
Receiving/composition additionally require pinned `admission` and `coverage`
files, the exact `receiver.registry()`, `CONTEXT_POLICY` and
`GEOMETRY_PREDICATES`. Legacy audit/addendum references are optional lineage.

An actual run also supplies `run_scope`: `allowed_operations`,
`permitted_native_sha256`, `permitted_physical_pages`, `allowed_adapters`,
`max_adapter_calls`, `max_engine_calls`, `engine_sha256`, and `output_root`.
This small explicit scope is not an owner-authorization service: operators remain
responsible for obtaining authority and freezing its exact manifest. Receiving
authority does not imply composition authority. The private predecessor's
historical actual-generation prohibition is not edited or inherited as new authority.

Original source identities, run pins, outputs, profiles, annotations and receipts
belong outside Git. Output creation is exclusive. Routine processing must not
target `00_external`, `01_raw` or `99_archive`.

## Receiving and evidence guarantees

Before RegionView creation, heading qualification or row generation, V002-derived
checks reject internal positive-area overlap in **both** axes, whole-box column
crossing, contradictory supplied single-run/gutter spanning, missing necessary
geometry and competing ownership. Edge/corner contact is not positive-area
overlap. Membership multiplicity/no duplicates and declared geometric sequence
are checked separately. Geometry is checked locally: overlaps in an already
ineligible neighboring region do not disable an independently accepted region.
Off-region intersections retain the existing rejection rule.

Known headings qualify only after structural admission: priority documentary
`N.° / Lugar / Caso / Situación`, or regional `Región / Total / %`.
Unknown or competing layouts do not dispatch. These headings never enter the
geometry-only detector. No unrestricted whole-page adapter is run and filtered.

RegionView retains original `/words/i`, own-`/text` spans, layout pointers, page
dimensions, native hash, admission hash/rule and a reversible local-to-original
map. Only admitted words supply headings, ordinals and cells. Priority stop and
unanchored-continuation safeguards may inspect logged off-region rectangles,
never off-region text. Literal word strings remain original; inserted spaces
and newlines in reconstructed cells are declared derivative syntax.
Regional TOTAL rows remain distinct from category measurements.

Native coordinates are `retained_native_page_words_region_v001`, with no claimed
conversion to image pixels, PDF MediaBox points or historical table-array boxes.
The adapter algorithm versions remain historical identities; wrappers and
compiled profiles identify this new portable pipeline separately.

The legacy importer retains failed audit/addendum references. It supports only
the declared column-membership predicate revision, independently checks full-box
membership, multiplicity and geometric sequence for the addressed source region,
and rejects unrelated/unmatched failures. No historical pass count or particular
region identifier grants eligibility.

## Outputs and interpretation

Admission and composition have separate seals. Composition retains a planned
dispatch ledger before generation, the first candidate, shared word-evidence
sidecar, derivative and scope accounting. A planned `dispatch` entry is not proof
of execution: actual candidate results, call accounting and generation markers
record what ran. The admitted scope includes headers/ordinals; returned cell-word
membership is reported separately. Partial candidates do not qualify a derivative.

All source words retain processing/accounting states; unresolved or unprocessed
words do not certify source absence. Complete word accounting is not semantic
page completeness, whole-PDF object recall or scientific accuracy. An abstaining
different-page development attempt can demonstrate enforced boundaries without
demonstrating extraction transfer. Development-seen units are not holdouts.
Formal readiness/milestone/release decisions remain separate and unchanged.
