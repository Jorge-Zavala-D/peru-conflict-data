## Common contract and dependency rules

Every task card below has an objective, inputs, outputs, direct dependencies, technical checks, PI role, completion criterion, exclusions, resource drivers and next handoff. All task dependencies resolve to successor task IDs; completed foundations are input evidence, not circular gates. Criteria describe what future completion requires, not an assertion that work has happened. Dependencies authorize no operation by themselves.

Official PDF bytes remain authoritative immutable published evidence. The workbook is complementary. Original Spanish strings, literal dates/precision, null/zero distinctions, stock/transition, case/event, event-level violence versus reported cumulative indicators, original/derived geography, explicit genealogy and source contradictions remain distinct. Material facts and relationships retain mechanically verified report/hash/page/section and representation-bound evidence. The 13 families and 74 participant fields are a retained measurement inventory, not a ceiling on canonical tables. Models cannot fill missing originals from external knowledge or make totals agree by changing source values.

All real inputs, raw responses, initial candidates, review decisions, corrected derivatives and canonical/export artifacts stay beneath the envelope-bound external data root. Git holds source-safe recipe, config, tests and documentation. Routine code does not write `00_external`, `01_raw` or `99_archive`; the operational acquisition ledger remains separately controlled in `01_raw/manifests`. Canonical Parquet/DuckDB materialization uses append-only adjudication lineage and no-replace releases. The historical five CSVs remain preserved interchange formats.

A future run needs actual source/unit hashes, permitted operations, purpose, actual model/tool configuration, external output location, iteration/call/token/wall-time/spend/review bounds and stops before execution. An omitted value never means unlimited authority. Routine code/test/retry work inside an authorized envelope is ordinary implementation; material corpus/regime expansion, changed scientific meaning, new provider/exposure/spend, canonical promotion and public release need the corresponding actual PI decision.

Native/layout/table evidence supplies reliable structure and exact positions; visual/multimodal routes are used where suitable; OCR is page-specific when evidence justifies it. Preserve mechanically generated representations separately from authoritative PDFs. Record actual available model/provider/settings/prompt/schema/config/packet/timestamp/status/retry/cost identities; do not invent seeds, snapshot IDs, costs or hidden reasoning. Retained outputs support reproducible materialization, not a promise of identical future stochastic responses.

## Evaluation and expansion gates

[The successor protocol](ai_pi_reference_evaluation_protocol.md) defines source-first versus assisted PI decisions, exact review coverage and separate origin/processing/use/release states. Machine consensus cannot create PI review, synthetic practice cannot become a real reference, and a reviewed sample cannot label the whole dataset human gold. Reference corrections create new versions and invalidate stale score applicability while retaining the old score.

Targeted queues resolve consequential, rare and ambiguous items. Probability-based source-unit audits estimate omissions/quality using a frame, selection probabilities, strata and actual coverage, including agreements and apparent-negative pages. They are not pooled as a random sample. Respect report/page/case clustering; fields within one case are not independent replications. Zero observed errors is not zero error probability.

Exploratory advancement requires a useful source-bound sample and workable PI loop. Regime qualification requires a frozen pipeline, scoped PI-reviewed reference/audit, reported discovery/field/evidence/relation performance, uncertainty, burden and actual PI scope decision. Public release additionally requires provenance/coverage/linkage closure, material issue dispositions, rights and explicit owner public scope.

Inherited central-field, discovery and page goals remain >=99%; critical evidence completeness, zero unresolved critical parser errors, arithmetic classification and medium-confidence-link review remain goals/requirements with their actual historical meaning. They are not new approved point estimates or confidence bounds. Every inherited metric is mapped in `inherited_metric_dispositions`; all registered object families remain reportable. Numerical object thresholds are still unselected and must be chosen from development/reference composition before final evaluation, with no abandoned two-RA/M2-03 completion trigger. Normative discovery-start/exact-boundary correspondence and normalized-date scoring require a reviewed versioned contract; silent replacement is prohibited.
