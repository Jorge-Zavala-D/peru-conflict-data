allowlisted worker packets, mechanical field/evidence checks and pure synthetic
review/derived-version/initial-prediction scoring interfaces. It reuses

The thin `scripts/plan_ai_pi.py` entry reads only the named strategy/envelope and
prints JSON. It has no model, acquisition, provider, canonical-write or release
dispatch. Example in an already prepared development environment:

```powershell
python scripts/plan_ai_pi.py --strategy config/ai_pi/strategy_v1.json --envelope <run.json>
```

The migration receipts use the separately verified installed interpreter/import
profile; this example is not an instruction to install dependencies or an approved
production launcher. Missing scope, actual owner execution authority, tool
configuration and budget are named. `executable=false` always means the extractor
is not implemented, even when these metadata are complete.

source-hash set; the envelope cannot admit its own source. Only source units and
neutral rules are projected, not evaluation slots, labels or reference decisions.
This is a narrow API boundary, not a new confidentiality certification or provider
sandbox.

Metadata distinguish origin, processing, intended use, exact reviewed fields/units,
inventory-reviewed units and release state. Pure validators establish shape,
identity and coverage, **not the authenticity of a declared PI reviewer**. The
current module makes no real PI claim, writes no history, and qualifies no release.

## Scientific/storage contract

The database reconstructs published monitoring, not all real events; the workbook
is complementary. Keep official bytes and alternatives immutable, Spanish source
values/date precision separate from derivatives, source-level missingness separate
from extraction failure, stock separate from transitions, case separate from event,
event violence separate from cumulative case indicators, and source aggregates
separate from derived counts. Preserve identity priority and explicit genealogy,
provenance, contradictions and append-only adjudication. Unknown is never zero.

Native/layout/table tools are preferred where they reliably support evidence;
model assistance need not wait for exhaustive deterministic extraction. Narrow
OCR requires page-specific need. External knowledge may not fill an absent
source-original fact. The 13 families/74 participant fields remain measurement
inventory, not a ceiling on canonical relational context.

Retain source, representation, prompt/tool/model identities, raw responses, initial
candidates, decisions, corrections and frozen scores separately. Reproducible
materialization from retained outputs does not promise identical future stochastic
responses. Public rights and release quality are separate owner decisions.
