# Release versioning

The retained `v0.1.0` directory is the M0 foundation snapshot; `v0.2.0` is the source-evidenced working contract for the M1/M2 baseline and is not a public data release. Future releases may use later schema versions after evidence and migration review. Model schemas are retained under actual directories; exporting a later schema version does not delete an earlier directory. Stable IDs use explicit scheme version `1` and a pinned golden vector before any canonical rows exist. Each release requires data, dictionary, schemas, code commit, source coverage/hashes, QA/benchmark evidence, known issues, adjudication summary, taxonomy version, changelog, checksums, citation, and licensing statement. Never overwrite a release. MIT covers repository software, not automatically source documents or derived-data redistribution rights.
