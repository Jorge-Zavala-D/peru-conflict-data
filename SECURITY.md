# Security and data handling

Never commit API keys, OAuth tokens, Dropbox/GitHub credentials, cookies, temporary links, `.env`, private keys, raw reports, administrative workbooks, respondent-level data, or generated databases. Use least-privilege connectors and review third-party MCP/plugin permissions. Model calls require documented data-use authority and minimal source segments. Report suspected credential or restricted-data exposure privately to the repository owner; do not open a public issue containing the material.
